# Papufy App — Capacitor

O app nativo exibe **a mesma experiência mobile do navegador** em
[papufy.com](https://papufy.com).

Guia completo de publicação: **[STORE.md](./STORE.md)**

## Setup

```bash
cd D:\Projetos\papufy-app
npm install
npx cap sync
```

- Android AAB: ver `STORE.md` (keystore + `gradlew bundleRelease`)
